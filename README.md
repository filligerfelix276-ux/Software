# CPNEDEV Board Test

This project contains the STM32 board test firmware for the CPNEDEV board.

## Project type
- STM32CubeIDE / STM32 project
- Intended for use in VS Code and GitHub version control

## Notes
- Keep generated build artifacts out of source control via the project `.gitignore`.
- Add this repository as a remote when you are ready to push to your F18 software GitHub repository.
